MVSEP Создатель Минусов (Дополнение NVDA)

Специальное дополнение NVDA для удаления вокала и создания профессиональных минусовок (инструменталов) из аудиофайлов.

Основные возможности

  • Фокус на создании минусов: BS Roformer, MelBand Roformer, SCNet, MDX23C, Karaoke, Удаление реверберации и др.
  • Система кредитов: Озвучивание списанных и оставшихся кредитов при создании минуса.
  • Избранные модели: Быстрый выбор часто используемых моделей (⭐).
  • Все модели: Доступ ко всем 35+ моделям MVSEP.
  • Без локального FFmpeg: Обработка происходит на облачных GPU серверах MVSEP.
  • Звуковые сигналы прогресса: Аудио обратная связь с повышением тона от 220 Гц до 1760 Гц.

Горячие клавиши

КлавишиДействие
NVDA + Alt + MСоздать минус (автоопределение выбранного аудиофайла в Проводнике)
NVDA + Alt + KОзвучить остаток кредитов на аккаунте MVSEP
NVDA + Alt + Shift + MОткрыть настройки MVSEP

Примечание: Все горячие клавиши можно переназначить в Параметры NVDA -> Жесты ввода.
