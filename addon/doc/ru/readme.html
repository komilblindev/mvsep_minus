Создатель минусовок MVSEP - Дополнение для NVDA

Специализированное дополнение для программы экранного доступа NVDA, предназначенное для качественного удаления вокала из аудиофайлов и создания минусовок / инструменталов профессионального уровня. Дополнение полностью интегрировано с официальным облачным API MVSEP.com.

📖 Руководство пользователя (Пошаговая инструкция)

Шаг 1: Подключение учетной записи и получение API-ключа

Для работы дополнения требуется бесплатный персональный API-ключ MVSEP.

⚠️ ВНИМАНИЕ: Проблема с доставкой писем подтверждения на почту!
В связи с особенностями почтовых серверов MVSEP, при обычной регистрации по email письмо со ссылкой подтверждения часто задерживается или вовсе не доставляется почтовыми сервисами (возникает статус Pending email verification).

Самый надежный, безошибочный и быстрый способ (за 1 минуту):
  1. Откройте Меню NVDA -> Параметры -> Настройки -> MVSEP Minus;
  2. Нажмите кнопку «Войти в систему...» или «Регистрация...»;
  3. В открывшемся диалоге нажмите кнопку «Получить через Google / Сайт (Открыть в браузере)»;
  4. На открывшейся странице MVSEP нажмите «Sign in with Google» (Войти через Google);
  5. На странице (https://mvsep.com/full_api) отобразится ваш готовый API Token, скопируйте его (Ctrl + C);
  6. Вставьте ключ в поле «Ключ MVSEP API» в настройках дополнения и нажмите «Проверить ключ API».

Шаг 2: Создание минусовки (Основной режим)

  1. Выберите в меню: Меню NVDA -> Сервис -> MVSEP: Разделение музыки (Создание минуса)...;
  2. Укажите аудиофайл или вставьте ссылку;
  3. Выберите модель (рекомендуется BS Roformer ⭐);
  4. Выберите формат (MP3, WAV, FLAC);
  5. Нажмите «Начать разделение». Результат сохранится в Загрузки/MVSEP_Minus.

Шаг 3: Быстрое фоновое разделение

Выделите файл в Проводнике и нажмите горячую клавишу для мгновенного запуска в фоне.

Шаг 4: История разделений на сайте

Кнопка «История разделений на сайте...» в настройках позволяет скачивать прошлые треки напрямую.

🌟 Основные возможности

  • Multi-Account: Управление несколькими аккаунтами;
  • Failover: Автопереключение на резервный аккаунт при исчерпании лимитов;
  • Очередь сервера: Проверка загрузки серверов;
  • Разделение по URL: Google Drive, Dropbox, MEGA и прямые ссылки;
  • Журнал ошибок: Запись в mvsep_errors.txt и отправка разработчику;
  • Не требуется FFmpeg;
  • 3 языка: Узбекский, русский и английский.

🎧 Модели искусственного интеллекта

В дополнение включены более 35 лучших моделей и все 119 официальных алгоритмов MVSEP:

  • Минусовки и вокал: BS Roformer ⭐, MelBand Roformer, SCNet Large, MDX23C, Demucs v4 HT, Karaoke (Backing vocals), Medley Vox, Choir & SATB;
  • Премиум-ансамбли: Ensemble 2x/4x/6x, BS Roformer SW (6 stems), Mega 53-stem;

  • Инструменты: Ударные, пианино, бас, гитара, скрипка, духовые и перкуссия.

⌨️ Жесты управления

Назначьте удобные горячие клавиши в меню:
Меню NVDA -> Параметры -> Жесты ввода -> Создатель минусовок MVSEP.
