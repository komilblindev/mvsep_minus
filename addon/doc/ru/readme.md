# MVSEP Создатель Минусов - Дополнение для NVDA

Специальное дополнение NVDA для удаления вокала и создания профессиональных **минусовок (инструменталов)** из аудиофайлов.

## Основные возможности
- **Фокус на создании минусов**: Лучшие модели нейросетей: BS Roformer, MelBand Roformer, SCNet, MDX23C, Karaoke, Удаление реверберации и др.
- **Система кредитов**: Озвучивание списанных и оставшихся кредитов при создании минуса.
- **Избранные модели**: Добавление часто используемых моделей в список избранного (⭐).
- **Все модели**: Доступ ко всем 35+ моделям разделения MVSEP.
- **Без FFmpeg**: Обработка происходит на облачных GPU серверах MVSEP, локальный FFmpeg не требуется.
- **Мультиязычность**: Русский, Узбекский и Английский интерфейсы.
- **Совместимость**: NVDA от версии 2019.3 до 2026.1+.

## Горячие клавиши (настраиваются в параметрах NVDA)
- `NVDA+Alt+M`: Открыть диалог создания минуса (автоопределение выбранного аудиофайла в Проводнике).
- `NVDA+Alt+K`: Озвучить остаток кредитов на аккаунте MVSEP.
- `NVDA+Alt+Shift+M`: Открыть настройки MVSEP.
