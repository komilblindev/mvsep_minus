# MVSEP Minus Creator - Дополнение для NVDA

Специализированное дополнение NVDA для удаления вокала и создания профессиональных **инструментальных / минусовок** из аудиофайлов.

## Функции
- **Фокус на Минусовки**: BS Roformer, MelBand Roformer, SCNet, MDX23C, Karaoke, De-reverb и другие топовые модели.
- **Уведомления о кредитах**: Озвучивает потраченные и оставшиеся кредиты после завершения.
- **Избранные модели**: Добавляйте в избранное и быстро выбирайте предпочтительные модели (★).
- **Все модели**: Доступ ко всем 35+ моделям разделения MVSEP.
- **FFmpeg не требуется**: Чистый Python HTTP-клиент; обработка выполняется на облачных GPU серверах.
- **Мультиязычность**: Полная поддержка английского, русского и узбекского языков.
- **Совместимость**: NVDA от 2019.3 до 2026.1+.

## Глобальные горячие клавиши (Настраиваются в жестах ввода NVDA)
- `NVDA+Shift+Alt+P`: Открыть окно разделения (автоматически определяет выбранный файл в проводнике).
- `NVDA+Shift+Alt+C`: Озвучить оставшиеся кредиты на аккаунте MVSEP.
- `NVDA+Shift+Alt+M`: Открыть настройки MVSEP.
- `NVDA+Shift+Alt+D`: Быстрый минус (Мгновенный автозапуск разделения для выбранного файла).

## Горячие клавиши окна разделения
- `B`: Быстрый старт разделения.
- `Escape`: Закрыть окно.
