# MVSEP Minus Creator - NVDA Add-on

Specialized NVDA add-on for removing vocals and creating professional **instrumental / minus** tracks from audio files.

## Features
- **Focused on Minus / Instrumental**: BS Roformer, MelBand Roformer, SCNet, MDX23C, Karaoke, De-reverb and more top-tier models.
- **Credit Notifications**: Announces spent and remaining credits upon completion.
- **Favorite Models**: Star and quickly select your preferred models (★).
- **All Models Explorer**: Access all 35+ MVSEP separation models.
- **No FFmpeg Required**: Pure Python HTTP client; processing is done on cloud GPU servers.
- **Multi-language**: English, Russian, and Uzbek fully supported.
- **Compatibility**: NVDA 2019.3 up to 2026.1+.

## Global Shortcuts (Customizable in NVDA Input Gestures)
- `NVDA+Shift+Alt+P`: Open Minus Separation dialog (auto-detects selected file in Explorer).
- `NVDA+Shift+Alt+C`: Announce remaining credits on MVSEP account.
- `NVDA+Shift+Alt+M`: Open MVSEP Settings.

## Dialog Shortcuts (Inside Separation Dialog)
- `B`: Instantly start separation.
- `Escape`: Close the dialog.
