MVSEP Minus Creator (NVDA Add-on)

Specialized NVDA add-on for removing vocals and creating professional instrumental / minus tracks from audio files via MVSEP API.

Features

  • Focused on Minus / Instrumental: BS Roformer, MelBand Roformer, SCNet, MDX23C, Karaoke, De-reverb and more top-tier models.
  • Credit Notifications: Announces spent and remaining credits upon completion.
  • Favorite Models: Star and quickly select your preferred models (⭐).
  • All Models Explorer: Access all 35+ MVSEP separation models.
  • No FFmpeg Required: Processing is done on cloud GPU servers.
  • Progress Beeps: NVDA rising audio tones from 220Hz to 1760Hz during upload and download.

Shortcuts

ShortcutAction
NVDA + Alt + MOpen Minus Separation dialog (auto-detects selected file in Explorer)
NVDA + Alt + KAnnounce remaining credits on MVSEP account
NVDA + Alt + Shift + MOpen MVSEP Settings

Note: All shortcuts are fully customizable in NVDA Menu -> Preferences -> Input Gestures.
